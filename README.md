# shigemitsu---neuroscience-thesis-

# This is my neuroscience thesis for the Department of Natural Sciences at Scripps and Pitzer College. 
# This project is part of the Spike-Lab at Pomona College, and has been made possible by Professor Yuqing Zhu and my collaborator, Riley Yoo. 
# This project explores when grid-like representations emerge in a neural network by training a series of tasks that demand progressively more "navigation" (from a static lookup, to a single implicit displacement, to full multi-step path integration) and measuring hexagonal grid-like structure in the hidden units at each rung.
